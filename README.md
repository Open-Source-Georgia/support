# Open Source Georgia: Support

Welcome! This is where you can join the community and get help.

## How this repo works

- **Issues** are for actions, such as asking to join the GitHub organization or reporting a problem.
- **Discussions** are for questions, ideas, and showing your work.

## FAQ

**How do I join the GitHub organization?**
Open an [issue](https://github.com/Open-Source-Georgia/support/issues/new?template=invitation.yml) asking to join. You will receive an invitation.

**How do I make my membership public?**
Go to the [organization page](https://github.com/Open-Source-Georgia), click **People**, find your name, and change the visibility from Private to Public.

**How do I get started with open source?**
Make your first pull request in [first-contributions](https://github.com/firstcontributions/first-contributions). If you get stuck, ask in `#help` on Discord.

**Where do I find a project to contribute to?**
Look for issues labeled `good first issue` on GitHub, or ask in the Discord.
